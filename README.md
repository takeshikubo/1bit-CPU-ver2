# 1bit-CPU-ver2
1bit-CPU回路ハンズオン

## 設計の説明
事前情報によると、ポリシリコン層を配線として使った人は過去にいないと伺いました。
そのうえで配線にポリシリコン層を使用しました。

## 工夫したポイント
前回提出した1bit-CPUでは、ポリシリコン層（物理特性）を考慮し一部分に使用しましたが、
今回はポリシリコン層で配線出来るところは全てポリシリコン層で接続したことです。

## 苦労したポイント
今までに無いものを作るという課題があり、
Geminiも交えてポリシリコン層（物理特性）を構造的に活かした提案の可能性を模索・検討いたしました。しかしながら、検討の結果、妥当性・有用性を持った構成を組み上げることが難しかったです。
